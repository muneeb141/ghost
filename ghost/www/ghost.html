Event Webhooks (Behind the Scenes)
When a Ghost User converts, the backend instantly dispatches a secure webhook to your configured integrations (like Zapier, Make.com, or HubSpot). This happens strictly Server-to-Server.
💡 How to test: Go to Ghost Settings > Integrations, enable Webhooks, and set the URL to http://localhost:9001. Run the local python listener below, trigger a conversion, and watch the JSON payload arrive instantly!
Show test_webhook.py script 
import http.server, json

class Handler(http.server.BaseHTTPRequestHandler):
    def do_POST(self):
        length = int(self.headers.get('Content-Length', 0))
        print(json.dumps(json.loads(self.rfile.read(length)), indent=2))
        self.send_response(200); self.end_headers()

print("Listening on port 9001...")
http.server.HTTPServer(('0.0.0.0', 9001), Handler).serve_forever()
